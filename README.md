## Entry

> Fixed a bug where users woke up at 3 a.m. to review every decision they made since 2011.

## How it works

`main.py` (standard library only) writes the line to `/output/entry.txt`,
first checking it against the bounty gate (UTF-8, 1–160 characters, not only
whitespace, a single line), then reading the file back to confirm it is
byte-identical to the entry.
